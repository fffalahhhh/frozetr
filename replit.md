# Frozen Shake Cash Tracker

A responsive, browser-only daily cash tracker for Frozen Shake.

## Run

- Start the Replit app with `npm run dev` (or `npm start`).
- The app is served on port 5000.
- No external services or sign-in are needed.

## Data

Daily revenue, expenses, handovers, and custom categories are saved in the current browser's local storage. They are not synced across devices. The app uses the Asia/Kolkata date for the default day.
